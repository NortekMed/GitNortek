### Privacy Policy

No data will be collected.

When **Show Avatars** is enabled, GitNortek may request commit-author images
from GitHub and Gravatar. GitHub requests include repository and commit IDs;
Gravatar requests include an MD5 hash of the commit author's normalized email
address. If no Gravatar exists and the author name is a valid GitHub username,
GitNortek may request that public GitHub profile image. Images are cached in
memory for the current session only. Disable **Show Avatars** in **Settings >
Window > View** to prevent these requests.
